# Lab 7 – Image Filtering Techniques

**Course:** Image Processing

**Objective:** Apply different image filtering techniques for sharpening and noise reduction.

**Part A – Laplacian Filter:**
- Apply manual and OpenCV Laplacian filters.
- Compare the original and sharpened images.

**Part B – Mathematical and Statistical Filters:**
- Generate different types of image noise.
- Apply Mean, Median, Max, Min, and Midpoint filters.
- Compare filtering results using different noise types and kernel sizes.

**Tools:** Python, NumPy, OpenCV, Matplotlib.
