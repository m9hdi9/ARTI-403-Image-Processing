# Lab 6 – Sobel Filtering in the Frequency Domain

**Course:** Image Processing

**Objective:** Apply Sobel X and Sobel Y filters in the frequency domain using FFT to detect image edges.

**Implementation:**
- Load and resize the Cameraman image.
- Apply Sobel X and Sobel Y using FFT.
- Use Inverse FFT to display the filtered results.

**Tools:** Python, NumPy, Matplotlib, Scikit-image.
